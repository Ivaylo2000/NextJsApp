<h2 align="center">Next.js E-Cpmmerce App</h2>
<h4 >This is a full-stack web application that allows users to register, browse and post products, and manage a shopping cart. The project is built with a modern tech stack including Next.js, TypeScript, Node.js, MongoDB, and Firebase.
</h4>

🖥️ Features

🔐 Authentication

- User registration with hashed passwords

- Email availability check

- Login via JWT tokens

- Backend validation for input fields

📸 Product Listings

 **Users can:**

- Upload, their own product

- View listings from all users

- Upload images (validated & stored on Firebase)

🛒 Shopping Cart

**Users can:**

- Add products to their cart
- The cart is stored locally in localStorage
