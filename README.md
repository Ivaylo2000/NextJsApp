# 🖥️ Features

### 🔐 Authentication

- User registration with hashed passwords
- Email availability check during signup
- JWT-based login system
- Backend input validation

### 📸 Product Listings

**Users can:**

- Upload and manage their own products
- Browse listings from all users
- Upload images (validated & stored securely on Firebase)
- Update product information
- Delete products (including associated image from Firebase)

### 🛒 Shopping Cart

**Users can:**

- Add products to their cart
- Cart data is saved in `localStorage` for persistence
